# How to Enable Light Mode in WebStorm

WebStorm offers several theme options, including light mode. This is an IDE setting and doesn't require any code changes.

## Steps to Enable Light Mode:

1. Open WebStorm
2. Access Preferences/Settings:
   - **macOS**: WebStorm → Preferences (⌘,)
   - **Windows/Linux**: File → Settings (Ctrl+Alt+S)
3. Navigate to: Appearance & Behavior → Appearance
4. In the "Theme" dropdown, select "IntelliJ Light" or another light theme
5. Click "Apply" then "OK"

The IDE will immediately switch to light mode.

## Additional Customization
You can further customize colors in Editor → Color Scheme if needed.
